# customer-shopping-analysis
Analyzed customer shopping behavior across 10 shopping malls (2021–2023) using SQL, Excel, and Power BI. Performed data cleaning, trend analysis, and customer segmentation based on gender, age group, product category, and payment method. Created an interactive dashboard to generate business insights and support decision-making.

# Customer Shopping Analysis

## Project Overview
Analyzed customer shopping behavior from 10 shopping malls (2021–2023).

## Tools Used
- SQL
- Power BI
- Excel

## Key Insights
- Customer trends by gender
- Age group analysis
- Product category analysis
- Payment method preferences

## Dashboard
Interactive Power BI dashboard created for business insights.
